# TICKET023 — Human-gated production provider policy, secrets, and gate integrity

- **Status:** Todo
- **Priority:** P1
- **Blocked by:** Human-approved provider retry, secret/cost, carrier-canary, and protected-gate decisions

## Goal

Complete the remaining production-only provider and protected-gate decisions after explicit human approval.
M1/M2 identity/RLS/composite tenant integrity and M4 trusted provider routing are complete; none of that is
authorization to enable carrier sends.

## Scope

- Configure and verify the provider webhook retry policy explicitly for HTTP status failures and timeouts; do not assume `Retry-After` causes redelivery under provider defaults.
- Before enabling the isolated live-test SMS path, provision and rotate a 32-256 character `LIVE_TEST_SMS_OPERATOR_TOKEN` through an approved server-side secret manager. The deterministic demo session is not operator identity, and the token must not enter source control, logs, browser configuration, or stored audit metadata.
- Before enabling paid single-contact Twilio Lookup, provision and rotate a separate 32-256 character `LIVE_LOOKUP_OPERATOR_TOKEN`, restrict who may supply its dedicated request header, and set an operator-owned usage/cost cap. The deterministic demo session is not authorization for a paid provider request, and the token must not enter source control, URLs, browser-delivered configuration, logs, or persistence.
- Have a human review and update the protected integrity gate so a missing manifest fails instead of self-authorizing new hashes, and anchor the manifest itself so changing expected hashes cannot silently authorize modified gate files.

## Out of scope

Real secrets, live-feature flag changes, destructive or production database operations, live messages, unattended edits to integrity-protected files, and new settings pages.

## Acceptance criteria

- [ ] Provider webhook URLs have a reviewed retry count/policy for `4xx`, `5xx`, connection, and read-timeout failures, with signature validation tested against connection-override fragments.
- [ ] A human provisions and verifies the live-test operator token through production secret management, confirms that public readiness exposes only counts/last-four hints, and exercises the bounded timeout plus idempotent `202` retry path without a second provider call.
- [ ] A human provisions the separate paid-lookup operator token and cost cap, verifies missing/mismatched authorization fails before provider fetch, and confirms provider phone mismatches fail without writing a contact.
- [ ] Missing or modified integrity-manifest evidence fails closed; any protected-gate change is human-reviewed and the integrity manifest is deliberately re-generated by a human.
- [ ] `npm run production-auth:check`, the completed M4 routing/RLS regressions, `npm run contracts:check`, and `npm run validate` pass in the approved environment before any carrier canary.

## Risks

A public demo session, missing/weak operator token, uncapped paid lookup, unreviewed provider retry behavior,
real-secret mishandling, or stale integrity hash can create a false production-ready signal. Keep all
production flags off until every acceptance item is evidenced.
